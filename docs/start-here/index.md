# Start Here

Install the extension, confirm the supported language mode, and try one template interaction.

| Page                                | Outcome                                                     |
| ----------------------------------- | ----------------------------------------------------------- |
| [Installation](installation.md)     | HTMX completion, hover, and diagnostics are active.         |
| [First Template](first-template.md) | A Django template uses an HTMX request and a local partial. |

The extension supports VS Code `html` documents and `django-html` documents supplied by `batisteo.vscode-django`.
